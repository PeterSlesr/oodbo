Version 1.0.0 · Windows 10 / 11 (64-bit)

The desktop app is the same forward-only writing tool, running on your own machine. Your projects are saved locally, and — only if you choose — synced to your own Google Drive or OneDrive. You can use it without connecting any cloud account.

Download for Windowsoodbo 1.0.0 · .exe installer

Need an MSI (for managed or silent installs)? Download the .msi.

Before you install

The installer is code-signed by Paul Alan Mercogliano. The first time you run it, Windows SmartScreen may still show a “Windows protected your PC” notice for a new publisher — choose More info, then Run anyway. This prompt goes away as more people install the app.

System requirements

  • Windows 10 or 11, 64-bit
  • A modern WebView2 runtime (already present on up-to-date Windows; the installer adds it if missing)

Prefer not to install?

oodbo also runs in your browser at oodbo.io — no download required.
